# Neural network audit — 22 September 2026

Scope: the active NN-only application, from 36-feature inference through Home, paper execution and independent manual-position guidance, plus the offline backtest tool.

## Confirmed defects and fixes

1. **High — Home and paper execution could disagree after a model file changed.** Home/positions used a reader that reloaded files automatically, while the paper engine kept its loaded model until restart. A disposable model reproduction showed Home SELL while the paper trader used BUY and opened a trade. All active consumers now share NeuralEngine.read and its applied model/cache. File replacement takes effect for everyone together when settings are applied or the app restarts. Reading predictions does not alter paper state, and existing candle identities still prevent duplicate trading.

2. **High — advisory SMC requests could consume the NN execution window before the paper engine ran.** A simulated 61-second SMC timeout caused an otherwise valid BUY to expire. The runtime now handles required NN inputs, inference and a fresh executable quote for every asset before making advisory SMC requests in that scan. It checks the clock again after inference; a genuinely late signal cannot trade using an old timestamp. Stops still run with valid quotes when NN inputs fail. Actual required-feed outages and elapsed execution windows still correctly prevent entries.

3. **High — a temporary missing quote could permanently suppress an NN exit notification.** HOLD-to-adverse transitions were consumed while the visible state was WAIT, and queued alerts were permanently retired on transient outages. Notification state now survives missing quotes/model inputs. A fresh quote can create or revalidate the current undelivered alert. Supporting classifications update the transition baseline even without a quote. Sent, running, failed or uncertain deliveries are not replayed; new/re-enabled positions cannot inherit older exits; disabled/closed/superseded alerts remain suppressed.

4. **Lower severity — offline intrabar stop timestamps incorrectly claimed candle-open execution.** OHLC only establishes that the stop was crossed during the candle. Reports now use candle-close confirmation for these inferred stops and mark the exact fill time as unknown. Gap stops and signal exits retain open-time execution, and terminal liquidation retains close-time execution. Fill prices, costs and return calculations are unchanged.

The outdated NN documentation was also updated to reflect NN-only paper trading and independent Home/Positions analysis.

- New coverage includes same-path model replacement, coordinated apply, paused analysis, missing models with active stops, stale cached inputs, all-asset timing under slow SMC requests, quote/inference timing, asset-level failures, long/short alert recovery, restart/deduplication, alert preferences and offline stop chronology.

These checks establish implementation behaviour, not predictive performance or profitability. The published frozen model's historical calibration and Binance-to-Kraken input differences remain documented modelling limitations.
